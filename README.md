# Data Poisoning: The Invisible Threat
A coding project to inform my research poster contest entry for the 2026 BCSWomen Colloquium.

### Usage
Open the Jupyter Notebook `fgsm.ipynb` in an interactive environment and have a play around with the final FGSM image manipulator at the bottom. There are three different models you can compare the performance of; you can change epsilon as much as you want.

**FGSM** (**F**ast **G**radient **S**ign **M**ethod) is a simple adversarial attack technique for vision models, like CNNs.
